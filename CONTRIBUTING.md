# Contributing

Thanks for your interest! This project is shared as-is and maintained on a best-effort basis.

- **Issues:** bug reports with a minimal description of your setup (camera model, OS,
  ffmpeg version, the failing step and its output) are the most useful.
- **Pull requests:** welcome, small and focused ones especially. Please run `pytest -q`
  first and add a test with synthetic data where it makes sense (see `tests/fixtures/synth.py`).
- **Never commit real footage, IGC files, music or personal data**, including in tests and
  examples. The test suite generates everything it needs.
- No response time is promised. Feel free to fork.
